# پنل مدیریت ویزیتور (`panel/`)

این پوشه، صفحهٔ وبِ پنل مدیریت سامانه است که **خودِ سرویس پایتونی** (`api/server.py`) آن را
روی همان پورت ۹۵۹۵ سرو می‌کند — بدون IIS، بدون وب‌سرور اضافه و بدون بستهٔ بیرونی.

```
panel/index.html            صفحهٔ پنل (فارسی، راست‌به‌چپ، سرمه‌ای یکدست)
panel/fonts/*.woff2         فونت وزیرمتن (SIL OFL 1.1)
panel/fonts/OFL.txt         مجوز فونت
```

## چه می‌کند
| بخش | نقطهٔ پایانی واقعی |
|---|---|
| وضعیت سرویس و اطلاعات پنل | `GET /api/config` |
| سلامت سرویس و دیتابیس سامانه | `GET /api/health` |
| تست اتصال SQL با سرور/کاربر/رمز وارد‌شده | `POST /api/db/test` |
| فهرست دیتابیس‌های سرور | `GET /api/db/databases` |
| خواندن تنظیمات فعلی (بدون رمز) | `GET /api/db/info` |
| ذخیرهٔ سرور/پورت/کاربر/رمز/دیتابیس در `config.json` | `POST /api/db/save` |
| وضعیت فعال‌سازی | `GET /api/activate` |
| ثبت کد فعال‌سازی | `POST /api/activate` |
| ورود مدیر و خواندن ویزیتورها | `POST /api/login` سپس `GET /api/visitors` |

## نکات امنیتی
* کلمهٔ عبور SQL **هرگز** از سرور خوانده یا نمایش داده نمی‌شود؛ `GET /api/db/info` فقط می‌گوید
  «تنظیم شده/نشده». نوشتن رمز فقط رو به سرور است و در `config.json` (پوشهٔ محافظت‌شدهٔ
  `C:\ProgramData\Vizitor`) می‌ماند.
* رمز مدیر در مرورگر فقط در حافظه نگه داشته می‌شود (هیچ `localStorage`/کوکی) و توکن هم پس از
  بستن صفحه از بین می‌رود.
* همهٔ درخواست‌های SQL از نوع **فقط‌خواندنی** هستند (`sys.databases`)؛ هیچ تغییری در دیتابیس
  مشتری انجام نمی‌شود.
* فایل‌های استاتیک فقط با پسوندهای مجاز (`html, css, js, woff2, png, jpg, svg, ico, txt, json`)
  و بدون امکان `..` سرو می‌شوند.

## اجرای محلی (برای آزمایش)
```
python api/server.py --config <path-to-config.json> --panel panel
```
سپس در مرورگر: `http://127.0.0.1:9595/`
