# آتیران ویزیتور (Vizitor)

> Developed by Milano Technical Team, Milad Yaghoobi

اپلیکیشن فروش و ویزیت سازمانی «آتیران ویزیتور» ویژه **پخش آجیل و خشکبار**، با معماری **آفلاین-اول**، متصل به دیتابیس حسابداری آتیران روی **SQL Server (پورت 1433)** از طریق وب‌سرویس **PHP 8.3**.

## معماری در یک نگاه

```
┌─────────────────────────── اپ اندروید (Kotlin + Jetpack Compose) ───────────────────────────┐
│  Room (کاتالوگ/مشتریان/فاکتورها) ←→ Repository ←→ Retrofit                                  │
│        ↑ سینک خودکار پس از اتصال شبکه: WorkManager (SyncWorker)                              │
└──────────────┬───────────────────────────────────────────────┬───────────────────────────────┘
               │ HTTP/JSON                                     │ HTTPS (بدون کلید در اپ)
        ┌──────▼──────┐                              ┌─────────▼────────────┐
        │  api.php    │──── PDO (sqlsrv/dblib) ────► │ Cloudflare Worker     │──► Google Gemini
        │  PHP 8.3    │      پورت 1433               │ پراکسی معکوس هوش مصنوعی │
        └──────┬──────┘                              └──────────────────────┘
               ▼
   SQL Server: CUSTOMERS ⋈ CustGroup | Products | SalesHeader + SalesLines | sal_mali
```

## ساختار مخزن

| مسیر | توضیح |
|---|---|
| `app/` | سورس کامل اپ اندروید (Kotlin، Jetpack Compose، Room، Retrofit، WorkManager، CameraX، ML Kit) |
| `server/api.php` | وب‌سرویس اصلی — تراکنش اتمیک صدور فاکتور روی `SalesHeader` + `SalesLines` |
| `server/config.php` | پیکربندی اتصال به پورت 1433 و نام جداول |
| `worker/` | پراکسی معکوس Cloudflare Workers برای کلید امن Gemini |
| `BUILD_INSTRUCTIONS.md` | **دستورات کامل بیلد و کامپایل APK (اندروید استودیو + Termux)** |

## تب‌های اپلیکیشن
1. **پیشخوان من** — نمودار دایره‌ای تارگت روزانه (سبز نئونی)، پورسانت لحظه‌ای، مشتریان نیازمند پیگیری (افت خرید)
2. **ویترین کالا** — کارت‌های شیشه‌ای با افکت سه‌بعدی (3D Tilt)، موجودی زنده، اسکنر بارکد
3. **سبد سفارش (FAB مرکزی)** — کسورات خودکار، امضای دیجیتال، دستیار هوش مصنوعی، «صدور و ارسال به آتیران»
4. **گشت‌زنی** — نشانگر اعتباری سبز/قرمز، مسیریابی شهری و بهینه‌سازی مسیر توزیع
5. **گزارشات و تنظیمات** — تاریخچه فاکتورها، پیکربندی سرور (IP + پورت 1433)، مدیریت همگام‌سازی، درباره ما

## شروع سریع

```bash
./gradlew clean
./gradlew assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```
