## ۱) درخواست و پاسخِ فنی

**درخواست:** «نسخهٔ انحصاری گزارشات مدیر را فقط بساز، با توجه به فایل apk جدید.»

**راه‌حل:** هر دو برنامه از **یک سورس** ساخته می‌شوند و «انحصاری» یعنی یک برنامهٔ
جداگانه با بستهٔ مستقل که **فقط** اتاق فرمان گزارش‌هاست:

| برنامه | بسته | نسخه | محتوا |
|---|---|---|---|
| آتیران ویزیتور (کامل) | `ir.atiran.vizitor` | `2.21.0-direct` | همهٔ امکانات ویزیتور + بخش گزارش مدیریت |
| **گزارشات مدیر** (انحصاری) | `ir.atiran.mreport` | `2.21.0-report` | فقط اتصال دقیق + جدول‌ها + گزارش‌ها |

هر دو با کلید امضای همیشگی امضا می‌شوند؛ بسته‌ها جداست، پس **کنار هم** نصب می‌شوند و
روی هم نمی‌افتند.

## ۲) طعم‌های ساخت (Gradle product flavors)

```kotlin
flavorDimensions += "edition"
productFlavors {
    create("vizitor") {                 // برنامهٔ کامل
        dimension = "edition"
        applicationId = "ir.atiran.vizitor"
        buildConfigField("boolean", "MR_EDITION", "false")
    }
    create("mreport") {                 // نسخهٔ انحصاری گزارشات مدیر
        dimension = "edition"
        applicationId = "ir.atiran.mreport"
        versionName = "2.21.0-report"
        buildConfigField("boolean", "MR_EDITION", "true")
    }
}
```

* نام برنامه از «منبع همان طعم» می‌آید: `src/vizitor/res/values/strings.xml`
  («آتیران ویزیتور») و `src/mreport/res/values/strings.xml` («گزارشات مدیر»)؛
  برای همین `app_name` از `src/main` برداشته شد (وگرنه تداخل منابع می‌شد).
* خروجی‌های Gradle: `app/build/outputs/apk/<flavor>/<buildType>/app-<flavor>-<buildType>.apk`.

## ۳) تغییرات کد (فایل‌به‌فایل)

| فایل | تغییر |
|---|---|
| `app/build.gradle.kts` | افزودن `flavorDimensions` + دو طعم + `BuildConfig.MR_EDITION` + نسخهٔ ۲۱۸۱۷/۲٫۲۱٫۰ |
| `VizitorApp.kt` | در طعم انحصاری فقط `SecureDbStore.init` و `MaSectionStore.init` اجرا می‌شود و از بقیهٔ راه‌اندازی (داده نمونه، `SyncWorker`، چت، چک) **بازمی‌گردد** |
| `MainActivity.kt` | `if (BuildConfig.MR_EDITION) MReportRoot() else VizitorRoot()` |
| `ui/screens/manager/MReportRoot.kt` (جدید) | ریشهٔ نسخهٔ انحصاری: `MaManagerScreen(onBack = finish, exclusive = true)` |
| `ui/screens/manager/MaManagerScreen.kt` | پارامتر `exclusive`؛ در این حالت پیش‌فرض‌های مرجع پر می‌شود و اگر اتصالی نباشد برنامه روی برگهٔ «تنظیم اتصال» باز می‌شود؛ عنوان نوار بالا «گزارشات مدیر» |
| `src/main/res/values/strings.xml` | حذف `app_name` (به دو منبع طعم منتقل شد) |
| `.github/workflows/build-vizitor-app.yml` | ساخت هر دو طعم، تولید `MReport-2.21.0-direct.apk`، ریلیز جداگانهٔ `manager-reports-2.21.0` |

## ۴) رفتار نسخهٔ انحصاری (تجربهٔ کاربر)

1. نصب → باز کردن «گزارشات مدیر» → برنامه **مستقیم روی برگهٔ «تنظیم اتصال»** باز می‌شود
   (همان حس صفحهٔ ورود برنامهٔ مرجع).
2. فیلدها از قبل با پیش‌فرض‌های مرجع پر شده‌اند:
   `37.143.147.19` · پورت `1433` · دیتابیس `Atiran2` · کاربر `AdminAn` — فقط رمز را
   وارد می‌کنید. (نشانی شبکهٔ داخلی `192.168.1.10` هم آماده است و با کلید
   «شبکهٔ داخلی / اینترنت» جابه‌جا می‌شود.)
3. «اتصال به سرور» → چهار حالت پشت سر هم امتحان می‌شود
   (Microsoft+TLS → Microsoft → jTDS → jTDS+TLS) و اولین موفق برنده است.
4. «عیب‌یابی اتصال» → گام‌به‌گام: هدف اتصال، سرویس SQL Browser (UDP 1434) با پیشنهاد
   پورت، دست‌دادن TCP، پاسخ واقعی TDS، TLS و ورود — با راهنمای فارسی هر گام.
5. پس از اتصال: «نمای کلی» جدول‌ها، «مرور داده‌ها» با صفحه‌بندی/جست‌وجو/جزئیات رکورد،
   «اتصال جداول» با تشخیص خودکار پنج بخش و «گزارش‌ها» با مجموع مبلغ، برترین‌ها
   (نمودار سه‌بعدی) و آخرین رکوردها — همه از دادهٔ واقعی سرور.
6. دکمهٔ بازگشت نوار بالا = خروج از برنامه (این نسخه صفحهٔ دیگری ندارد).

## ۵) آزمون‌های پیشنهادی روی دستگاه

| # | آزمون | نتیجهٔ درست |
|---|---|---|
| ۱ | باز کردن برنامه در اولین اجرا | مستقیم روی «تنظیم اتصال» با پیش‌فرض‌های پر |

| ۵ | «دریافت فهرست جداول سرور» | تعداد جدول‌ها، مجموع رکوردها و حجم دیتابیس |
| ۶ | «تشخیص خودکار جداول» | اتصال پنج بخش به جدول‌های واقعی + نقش ستون‌ها |

## ۶) محدودیت‌های صادقانه

* نسخهٔ انحصاری **عمداً** بدون ویترین، سبد خرید، ثبت ویزیت، چت، یادآور شمسی و
  همگام‌سازی پس‌زمینه است — همان «فقط گزارشات مدیر» که خواسته شد. اگر بعداً لازم شد،
  هر بخش با یک خط شرط از سورس مشترک به همین نسخه هم اضافه می‌شود.
* «مجموع مبلغ» و «برترین‌ها» به تشخیص ستون مبلغ وابسته‌اند؛ اگر نام ستون ناآشنا بود،
  «نقش ستون‌ها» را در کارت بخش ببینید و جدول را دستی تنظیم کنید.
* اتصال فقط-خواندنی است (قاعدهٔ خود مرجع): هیچ داده‌ای روی سرور تغییر نمی‌کند.
* سرویس SQL Browser روی UDP 1434 در بسیاری از شبکه‌ها بسته است؛ در آن حالت پورت واقعی
  را دستی وارد کنید.
